SPACE INVADERS v0.1
===================
released 2026-07-29

Make sure you have downloaded the correct version for your machine.

Double-click on `invaders.exe` to start the program.
You can also launch it from the command-line with no arguments.

- Press C to insert coins, then press 1 or 2 to start a single- or
  two-player game.
- Use the arrow keys or A-W-D to play. Press UP or W to shoot.
- Press DEL to tilt the game. WARNING: instant game over!

Your high-score is saved when you quit the game, so you can try to beat it
when you come back. You can also try to edit the savefile (data/score.bin)
but watch out! Things can get weird ;)

Source code and updates can be found at the project page:
https://github.com/slaimon/invaders
